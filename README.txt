Название: Калькулятор ферментера для производства лимонной кислоты / Citric Acid Fermenter Calculator

Стек: Python, Tkinter

Что делает: Рассчитывает параметры ферментера для производства лимонной кислоты (объёмы, расход воздуха, тепловую мощность, площадь теплообмена) по кинетическим и тепловым данным.
